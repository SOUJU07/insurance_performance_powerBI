# Insurance Performance Power BI Dashboard

Power BI solution for analysing life insurance agency sales performance, agent targets, product contribution, and policy persistency.

## Project Objective

The dashboard is designed to help agency leaders monitor:

- Agent performance against APE targets
- Product contribution to premium income
- Policy renewal and persistency performance

## Data Sources

The project uses the following CSV datasets:

- `dim_date.csv`
- `dim_agent.csv`
- `dim_product.csv`
- `fact_sales.csv`
- `fact_target.csv`
- `fact_persistency.csv`
